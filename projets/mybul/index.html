Bulle d'Autonomie · aidants familiaux · mobile + web

MyBul

L'outil qui relie les proches aidants à leur coordinatrice autonomie, et les entreprises à leurs salariés aidants.

Rôle
Lead developer Flutter
Période
oct. 2022 → 2024
Stack
Flutter · Appwrite · Node · TypeScript
Plateformes
iOS, Android, web

Problème

11 millions d'aidants en France, dont 75 % se disent stressés, fatigués et isolés. Un salarié sur cinq est concerné. Bulle d'Autonomie prend le relais avec une coordinatrice autonomie ; il lui fallait un outil pour porter la relation, le suivi et les ressources.

Rôle

Lead developer d'une équipe de six : architecture Flutter en couches, une seule base de code pour l'app aidant et la plateforme web, API Node et Appwrite auto-hébergé, migrations, publication sur les stores.

Résultat

Cinq rôles servis par un même produit : aidant, salarié aidant, coordinateur, référent entreprise, admin. Visio, abonnements et paiement in-app, chatbot, espace entreprise déployé pour les salariés aidants de Groupama, client de Bulle d'Autonomie. Deux ans de collaboration.

Périmètre

  • Inscription en 7 étapes avec rattachement à une entreprise
  • Messagerie, visioconférence et chatbot « Bulle »
  • Abonnements et paiement in-app (App Store, Google Play)
  • Agenda, missions, transmissions et documents côté coordinateur
  • Espace entreprise : besoin de temps, de parler, d'informations

Comment c'est fait

Architecture
Présentation → application → domaine → infrastructure. Cubits, freezed, Either pour les erreurs.
Trois cibles
lib/app (mobile), lib/web (plateforme), lib/common (partagé). Flavors dev / prod, deep links.
Back
Appwrite auto-hébergé (auth, base, stockage), API Node TypeScript, migrations maison, OpenAPI.
Qualité
Sentry, InfluxDB pour les métriques, CI GitLab, FVM pour aligner l'équipe.
Équipe
6 contributeurs, 1 300 commits app et API.
